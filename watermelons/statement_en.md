# Watermelons

Uil and Giraf are buying watermelons. At the supermarket, there are `n` watermelons, each with a different weight (watermelon number `i` has weight `wi`).

They want to make sure they only buy the watermelons that can be exactly split into two parts of integer weight, where one half has the exact same weight as the other half.

What is the maximum number of watermelons Uil and Giraf can buy?

## Input
```
n
w1 w2 w3 ... wn
```

- One line with `n`, the number of watermelonds
- One line with n numbers, each representing the weight of each watermelon

## Output
One line with one number: the maximum number of watermelons they can buy

## Samples
### Sample Input 1
```
5
1 2 3 4 5
```

### Sample Output 1
```
2
```

There are 5 watermelons, but only 2 watermelons can be split into two equal parts with integer weights.
