# Chairs
We are going to organise another EGOI cursisdag!!! (Yipee!!!)

However, there might not be enough chairs :(

We know that `n` girls signed up for the cursisdag and there are `k` chairs in the informatica wittekerkje. Are there enough chairs for all the girls?

## Input
```
n k
```

## Output
One line with `ja` (if there are enough chairs) or `nee` (if there are not enough chairs).

## Sample
### Sample input 1
```
10 10
```

### Sample output 1
```
ja
```

### Sample input 2
```
100 10
```

### Sample output 2
```
nee
```
