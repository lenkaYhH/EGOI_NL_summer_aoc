# Stoelen

We gaan weer een EGOI cursisdag organiseren!!! (Yayyyy!!!)

Er zijn echter misschien niet genoeg stoelen :(

We weten dat $n$ meisjes zich hebben ingeschreven voor de cursisdag en dat er $k$ stoelen zijn in het informatica wittekerkje. Zijn er genoeg stoelen voor alle meisjes?

## Invoer
```
n k
```

## Uitvoer
Één regel met `ja` (als er genoeg stoelen zijn) of `nee` (als er niet genoeg stoelen zijn).

## Voorbeelden

### Voorbeeldinvoer 1
```
10 10
```

### Voorbeelduitvoer 1
```
ja
```

### Voorbeeldinvoer 2
```
100 10
```

### Voorbeelduitvoer 2
```
nee
```
