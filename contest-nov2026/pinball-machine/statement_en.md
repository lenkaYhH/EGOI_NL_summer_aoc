# Pinball Machine

You are a programmer at the company that build pinball machines. You have been tasked to fix the software for the pinball machines at the informatica wittekerkje!!
Seems like the feature to remember max score is missing. Write a program that remembers who got max score.

## Input
```
n
naam_1 score_1
naam_2 score_2
...
naam_n score_n
```

- one line with `n`, the number of people
- `n` lines follow, each with a string of someone's name and an integer for their score

It is guaranteed that all scores are positive and nobody has the same score. 

## Output
- one line with the name of the person with the max score

## Samples
### Sample input 1
```
2
Uil 10
Giraffe 11
```

### Sample output 1
```
Giraffe
```

### Sample input 2
```
1
Lenka 100
```

### Sample output 2
```
Lenka
```
