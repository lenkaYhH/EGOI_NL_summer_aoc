# Buying Cookies

For our next cursisdag we want to buy cookies! We have `n` girls, and the cookies come in packets of `k` cookie per bag. 
What is the minimum number of bags we need to ensure every girl has a cookie?

## Input
```
n k 
```

## Output
- One line with an integer: how many bags of cookie we need to buy

## Samples
### Sample input 1
```
10 4
```

### Sample output 1
```
3
```

### Sample input 2
```
100 2
```

### Sample output 2
```
50
```
