# De 99 Opgave

Uil begint een fietsenwinkel. Vroeger bepaalde Uil de prijzen van producten nogal willekeurig, maar nu heeft Uil besloten dat het winstgevender zou zijn als de prijzen op **99** eindigen.

Je krijgt een positief geheel getal `N`, de prijs van een product.

Je taak is om het dichtstbijzijnde positieve gehele getal bij **N** te vinden dat eindigt op **99**. Als er twee zulke getallen zijn die even dichtbij liggen, kies dan het grootste.

Bron: Kattis, <https://open.kattis.com/problems/99problems>

## Invoer

De invoer bevat één geheel getal `N` (**1 ≤ N ≤ 10^4**), de prijs van een product. Het is gegarandeerd dat `N` niet eindigt op 99.

## Uitvoer

Print één geheel getal: het dichtstbijzijnde positieve gehele getal dat eindigt op **99**. In geval van een gelijke afstand, print het grootste getal.

## Voorbeeldinvoer 1

```text
10
```

## Voorbeelduitvoer 1

```text
99
```

## Voorbeeldinvoer 2

```text
249
```

## Voorbeelduitvoer 2

```text
299
```

## Voorbeeldinvoer 3

```text
10000
```

## Voorbeelduitvoer 3

```text
9999
```
