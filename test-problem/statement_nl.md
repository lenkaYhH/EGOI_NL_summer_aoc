# De zeer gefocuste Giraffe

Uil de Pinguin probeert de zin "Hello world!" bij Giraffe over te brengen. Maar de Giraffe is op dit moment erg gefocust op het oplossen van een informaticaprobleem. Het duurt namelijk `n` keer voordat Giraffe Uil hoort zeggen "Hello world!". Gegeven `n`, geef "Hello world!" zo vaak uit als Uil moet roepen.

## Invoer

`n` op één regel, `1 <= n <= 100`

## Uitvoer

Geef `n` regels uit, waarbij elke regel de tekst `Hello world!` bevat.
(Hint: let goed op hoofdletters/kleine letters en de spelling!)

## Voorbeeld

### Voorbeeld invoer

`2`

### Voorbeeld uitvoer

```
Hello world!
Hello world!
```
