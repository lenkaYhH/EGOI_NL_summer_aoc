# The very focused Giraffe

Uil the Penguin is trying to get the message "Hello world!" to Giraffe. However, the Giraffe is very focused right now in solving an informatics problem. Specifically, it will take Uil `n` times in shouting "Hello world!" before Giraffe hears Uil. Given `n`, output "Hello world!" as many times as Uil needs to shout it.

## Input
`n` on one line, `1 <= n <= 100`

## Output
Output `n` lines, each line containing `Hello world!`
(Hint: Be careful of upper/lowercase and spelling!)

## Sample 

### Sample input
`2`

### Sample output
```
Hello world!
Hello world!
```
