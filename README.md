# Advent of Code, Summer 2026
Made for EGOI Cursis @ Informatica Olympiade

Collection of 40 beginner-level programming problems, cover the first chapters of the girls@informaticaolympiade cursis. 
Problems can be submitted online via the private Cuttle group of the EGOI cursis. 

Problem sources: Nederlandse Informatica Olympiade, EGOI, various open-source problems online, and a few original problems by me
