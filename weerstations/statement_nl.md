# Weerstations

De thermometer van uil is kapot, maar toch wil ze weten wat de temperatuure is. Gelukkig zijn er `n` weerstations op ongeveer gelijke afstand van hen. Uil denkt dat de temperatuur bij ze gelijk is aan het gemiddelde van de gemeten temperaturen bij de weerstations. Bereken deze temperatuur*. 

*Het is gegarandeerd dat alle gemeten temperaturen en de gemiddelde temperatuur is een geheel getal.

## Invoer
```
n
t1 t2 ... tn
```

Één regel met `n`, het aantal weerstations
Één regel met n getallen (die mag een decimal zijn!), die zijn de temperaturen gemeten bij de weerstations. 

## Uitvoer
Één regel met een geheel getal: de gemiddelde temperatuur.

## Voorbeeld
### Voorbeeldinvoer 1
```
3
1 2 3
```

### Voorbeelduitvoer 1
```
2
```
**Uitleg:** de gemiddelde temperatuur is (1.1+2+2.9)/3 = 2
