# Room Booking

Uil is booking rooms for the next EGOI trainingsweekend. There will be `n` girls coming to the trainingsweekend, and each room in the hotel can sleep `k` people. How many rooms need to be booked?

## Input
One line with two space-separated integers, `n k`

## Output
One number describing the number of rooms

## Samples
### Sample Input 1
```
10 2
```
### Sample Output 1
```
5
```

Explanation: there are 10 girls and we need to make rooms of 2. Uil needs to book 5 rooms. 

### Sample Input 2
```
11 3
```

### Sample Output 2
```
4
```

Explanation: there are 11 girls and we need to make rooms of 3. We need to book 4 rooms to fit 11 girls. (3 rooms is too little!)
